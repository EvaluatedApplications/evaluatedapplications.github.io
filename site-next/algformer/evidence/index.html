What attention costs

At the same shape and the same parameter count, reading a 1,984-token prompt takes 182 ms with softmax attention and 7.08 ms with holographic attention. Each further token takes 181 µs against 3.60 µs, and the serve cache holds 2,253 KB against 3.40 KB. Softmax reading grows with the square of the length (exponent 1.9) and holographic reading grows in step with it (1.0).

Where it is slower

Every loss in this record, stated once
  • Holographic attention holds a limited number of items cleanly in one bundle, and HoloShape reports how many for a shape (the capacity table). Softmax attention has no such bound, at the cost of everything above.

How it was measured

Stated once, for every figure on this page
Workload
Both cores are built at 32 channels, 8 shifts and 2 layers, which gives them the same parameter count, and driven with the same random tokens. For each context length the run reads the prompt through the serve cache, then produces 16 more tokens and averages them. Cache memory is the managed memory kept alive by the primed cache.
Engines
AlgFormer (softmax attention); HoloFormer (holographic attention)
Check
Both cores are warmed at every length before timing, so compilation has settled. The two have identical parameter counts.
Statistic
Median of 7 runs per length, on one thread.
Machine
16 logical processors; the run used one thread.
Ties
This measures cost only. It says nothing about which core predicts better.
