Many small models, one wave: the evidence

Six atoms that each see about a sixth of the text and share the medium score 2.99 bits per character. One atom that sees all of it scores 3.38, and the same six atoms without the medium score 4.33. At width 32, a pair scores 3.47 when the loss reaches the atoms through the notes they wrote and 3.84 when the writers are frozen.

Where the evidence stops

Every loss in this record, stated once
  • The harness results are small models on one text, two seeds, scored on windows of that text.
  • The six-atom checkpoints are scored on windows of their training text, and their two training rounds differ, so the table is not a comparison of the two settings.

How it was measured

Stated once, for every figure on this page
Workload
Bits per character on 300 held-out windows of the same text, scored at the last position, drawn the same way for every arm. The text is 300,000 characters of Gutenberg prose with a 64-symbol vocabulary. Each atom is a HoloFormer with shifts equal to the width, two layers, trained with the all-positions loss, learning rate 0.01, batch 16. The width-64 rows ran 800 steps at context 64. The width-32 rows ran 500 steps at context 32. The two groups are separate runs.
Engines
AtomField with Memory coupling (the shared medium); The same atoms with the field switched off; One HoloFormer reading the whole window
Check
Every arm is drawn the same way and scored the same way, with the matching null beside each result.
Statistic
Two seeds per arm.
Machine
The fused GPU step ran on an A3000 GPU at width 66, three passes, window 64, batch 32, fused path.

Small-scale harness, character language model

At width 64, six atoms that each see about a sixth of the text and share the medium score 2.99 (seeds 2.96 and 3.02). One atom that sees all of it scores 3.38 (seeds 3.25 and 3.51). The same six atoms without the medium score 4.33. At width 32, the pair scores 3.47 when the loss reaches the atoms through the notes they wrote, and 3.84 when the writers are frozen.

Six-atom checkpoints

Two six-atom checkpoints, each with six atoms at width 66 and six layers, Memory coupling and a 320-token vocabulary, scored on 400 windows of 65 tokens drawn from their training text, with all 64 transitions of each window scored. The two were stopped at different training rounds (3,510 and 9,000), so their scores are not a comparison of the two settings.

Fused GPU step

AlgFormer.Gpu stacks the atoms as a batch dimension, so every layer, pass, head, reverse and Adam kernel runs once for all atoms. The number of kernel launches per step does not depend on the number of atoms.

Limits

  • The atom field is opt-in in the library and the studio. A plain HoloFormer is what you get by default.
  • Cost is linear in the number of atoms with holographic locality or no locality. Dense locality is quadratic in the number of atoms.
  • The diversity options (golden rotation of timescales, golden-angle write phases) are off by default. In the width-64 four-atom test, rotation raised how much the atoms depend on each other (leave-one-out cost 0.16 to 0.21) without lowering their correlation or improving the score.
