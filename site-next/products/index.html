Products

High-performance .NET libraries. Each one is a NuGet package, and most build on the same two foundations.

Foundation

The base the rest is built on

  • Phasor

    Build stores that answer exactly, replicas that sync by their differences and tables that repair themselves. One pass applies a thousand operators.

    2.17.0NuGet package

  • EvalApp

    Resource-gated concurrency that tunes itself, sagas with compensation, middleware and a fluent builder. The execution engine under the other libraries.

    4.4.12 packages

Data

One store, queried three ways

  • HoloDb

    Answers exact, similarity and aggregate queries from one store, with transactions, a larger-than-memory paged engine, and a networked client.

    5.1.23 packages

Models

Transformers and the tools around them

  • AlgFormer

    Two interchangeable attention cores, classic softmax and holographic, in pure managed code, with optional GPU acceleration.

    3.3.02 packages

  • Prism

    The package behind the Prism tool: a confidence-gated decode policy, an append-only lineage journal and growth tools for AlgFormer models.

    1.3.4NuGet package

  • Prose

    Mines real text with deterministic grammar rules into a HoloDb database, then recombines it into new sentences and question and answer pairs.

    1.4.0NuGet package

Spatial and games

Movement, tactics and voxels

  • Tracer

    Navmesh pathfinding for crowds: swarms that share goals, dynamic obstacles, line of sight and combat, tuned to your frame budget.

    2.0.2NuGet package

  • HoloVoxel

    Level of detail is a property of the read: near data stays crisp and far data degrades gracefully, with SIMD throughout.

    1.5.2NuGet package
