Products

Drop a database, a language model or a crowd pathfinder into your app with one command.

NuGet packages for .NET. Most build on the same two foundations, so they fit together.

Try them in your browser

Foundation

The base the rest is built on

  • Phasor

    Build stores that answer exactly, replicas that sync by their differences and tables that repair themselves. One pass applies a thousand operators.

    2.21.1NuGet package

  • EvalApp

    Run everything at once without overloading anything. Gates on every resource, sagas that undo failures, and a tuner that finds the right speed.

    4.4.12 packages

Data

One store, queried three ways

  • HoloDb

    A SQL database inside your app that answers dashboard queries in microseconds, with transactions, similarity search and tables bigger than memory.

    6.0.13 packages

Models

Transformers and the tools around them

  • AlgFormer

    Train and run language models in plain C#. The holographic attention core reads long prompts in a fraction of the time.

    3.3.02 packages

  • Prism

    A model that remembers how it grew. A confidence-gated decoder and a journal of every change, behind the Prism chat tool.

    1.3.4NuGet package

  • Prose

    Three novels in, nearly two thousand checked new sentences out. Mines grammar into HoloDb and recombines it into text and question and answer pairs.

    1.4.0NuGet package

Science

Measured physics, graded against the lab

  • HoloGenome

    Turn DNA into a vector that winds like the real helix, then check it against laboratory measurements it never saw. The wins and the losses are published.

    0.1.1NuGet package

Spatial and games

Movement, tactics and voxels

  • Tracer

    Send a whole crowd to one exit with a single search. Navmesh pathfinding with dynamic obstacles, line of sight and combat.

    2.0.2NuGet package

  • HoloVoxel

    Voxel worlds that stay crisp up close and cost almost nothing far away, with no mesh tiers and no popping.

    1.5.2NuGet package

Web

Blazor pages that read first and run when asked

  • Blazier

    Blazor pages that read at once and download .NET only when a visitor presses Start, with long C# jobs in a Web Worker.

    1.1.0NuGet package
