What Prism is

Prism is the NuGet package that the Prism chat tool runs on. It holds three things for a model built on AlgFormer: the decode policy that chooses each next token, a lineage journal that records how the model grew, and a growth surface that changes the model and writes that record for you.

  • One decode policy

    Commit greedily when the model is confident, otherwise sample only from what clears the floor. The gate is one tested policy with an explicit floor mode: a resonance floor for the holographic core, no floor, or nucleus sampling.

  • Facts about the past stay facts

    Every structural change is stamped with the parameters a later calculation needs, when it happens. Questions such as how ramped a layer is, or when the model last grew, are answered from that history and never from whatever a live constant holds today.

  • Growth that records itself

    Growing context, layers, shifts or vocabulary through the growth surface stamps the journal automatically, so a model cannot grow without the record.

Capabilities

  • Lineage journal

    Idempotent append, so a resumed process stamping the same event again is a no-op. Derivations AlphaAt, DepthAt, LastGrowthRound and AddRoundOf resolve against the stamped history, including layers inserted at the front.

  • Storage seam

    A file-backed JSONL store with durable append, and a pure in-memory store for browser and WebAssembly hosts that have no file system.

  • Growth surface

    Grow a HoloFormer's context, layers, shifts or vocabulary, correct by construction, with the lineage stamped for you.

  • Decode policy and gate

    DecodePolicy, Gate and GateDecision implement the confidence-gated decode with an explicit FloorMode.

  • Degeneration guard

    DegenGuard fires on a run of repeated tokens or a run of non-greedy picks, the two signs that decoding has collapsed.
