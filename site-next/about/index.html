About

Evaluated Applications is an independent AI research lab in England. It builds the parts most AI work takes for granted, and publishes them as .NET libraries you can install and run.

What is built

  • Phasor holds the Pleroma: one fixed-size array of exact integers that answers fifty different questions in a single pass over it.
  • AlgFormer and its HoloFormer core: a language-model engine for plain C# where reading a prompt grows with its length, not its square.
  • HoloDb: a SQL database with exact aggregates, similarity search inside SQL, and real NULL.
  • EvalApp: the pipeline runner that spreads work across the cores you have.
  • Prose, Tracer, HoloGenome, HoloVoxel and Blazier, each one library with one job.

All of them are on Products. Several run in a browser tab under Tools.

How results are reported

Every number is published with the conditions it was measured in. The places where the work lost are listed beside the places where it won, on the Evidence pages. When a claim stops being true, the page changes. The pages describe what the code does today and nothing else.
