Summary

Evaluated Applications is a small independent lab in England that builds high-performance .NET libraries. Most of them share one idea: computing with holographic vectors, on a runtime that tunes itself to your hardware.

The core model, HoloFormer, replaces standard attention with holographic binding. Keys and values are bound together and superposed into a single memory trace, so attention costs O(T d) instead of O(T squared d), and serving each new token costs a constant amount instead of growing with context.

The energy cost of AI is worth attacking from the architecture up, not only from bigger data centres. That is why the work is shared in the open as libraries on NuGet and as tools that run in a browser tab.
