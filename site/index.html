Foundation

the base everything shares

Phasor

v1.0.1
EvaluatedApplications.Phasor

Vector-symbolic computing for .NET. Bind, bundle, and unbind hyperdimensional / phasor (HRR) vectors with a SIMD codec — the holographic primitive the rest of these libraries are built on.

dotnet add package EvaluatedApplications.Phasor
NuGet →

EvalApp

v1.5.0
EvaluatedApplications.EvalApp

An async pipeline runtime: resource-gated concurrency with adaptive self-tuning, sagas with compensation, middleware, and a fluent builder. The shared execution engine underneath the other libraries.

Does the work of a MediatR + Polly + Dataflow stack — one dependency, ⅓ the allocation, zero dropped requests. See the benchmark →

dotnet add package EvaluatedApplications.EvalApp
Benchmark →NuGet

HoloDb

v1.7.0
EvaluatedApplications.HoloDb

An embeddable holographic SQL database. Real ACID with a write-ahead log; whole-table and GROUP BY aggregates answered in microseconds from maintained accumulators (no scan); holographic NEAREST vector search; and a durable, larger-than-memory paged engine that spills to disk.

Same SQL, same data, verified identical vs DuckDB & SQL Server — microsecond aggregates that don't grow with your data. See the benchmarks →

dotnet add package EvaluatedApplications.HoloDb
Explore →Manual →NuGet

HoloDb.Client

v1.0.0
EvaluatedApplications.HoloDb.Client

The .NET client for a remote HoloDb server. Connect over TLS with a token, then run SQL and bulk-load with the same surface as the in-process engine. Columnar results stay columnar on the wire.

dotnet add package EvaluatedApplications.HoloDb.Client

How it fits together

These aren't nine unrelated packages. Phasor is the vector-symbolic core — the holographic math. EvalApp is the runtime that schedules and self-tunes the heavy work. HoloDb, AlgFormer, Tracer, and HoloVoxel are what you get when you build a database, a neural network, a game-AI SDK, and a spatial engine on that same foundation.
