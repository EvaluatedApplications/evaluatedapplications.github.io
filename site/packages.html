11 .NET libraries · one shared foundation

Eleven packages, one holographic foundation.

These aren't eleven unrelated packages. Phasor is the vector-symbolic core — the holographic math. EvalApp is the runtime that schedules and self-tunes the heavy work. HoloDb, AlgFormer, Tracer, and HoloVoxel are what you get when you build a database, a transformer, a game-AI SDK, and a spatial engine on that same foundation — and the rest extend those four. Four of these libraries also power the free tools live on the homepage right now; every one of the eleven is real, shipped, and on NuGet today.

Phasor

v1.0.3
EvaluatedApplications.Phasor

Vector-symbolic computing for .NET. Bind, bundle, and unbind hyperdimensional / phasor (HRR) vectors with a SIMD codec — the holographic primitive the rest of these libraries are built on.

EvalApp

v1.6.1
EvaluatedApplications.EvalApp

An async pipeline runtime: resource-gated concurrency with adaptive self-tuning, sagas with compensation, middleware, and a fluent builder. The shared execution engine underneath the other libraries.

One in-process dependency in place of a DI container + MediatR + Polly + TPL Dataflow. See how it works →

dotnet add package EvaluatedApplications.EvalApp
Explore →NuGet

Data

a holographic SQL database, embedded or networked

HoloDb

v1.7.7
EvaluatedApplications.HoloDb

An embeddable holographic database: data stored as one associative store and queried three ways over one copy — exact SQL by key, similarity by content (NEAREST), and constant-time aggregates. Real ACID with a write-ahead log, and a durable, larger-than-memory paged engine that spills to disk.

On a 10M-invoice ledger joined to 200k customers, the dashboard rollups resolve in microseconds and stay flat as the ledger grows — same SQL, same data, single-table and cross-table joins, verified identical against DuckDB and SQL Server. See the benchmarks →

dotnet add package EvaluatedApplications.HoloDb
Explore →Manual →NuGet

v1.4.0
EvaluatedApplications.HoloDb.Client

The .NET client for a remote HoloDb server. Connect over TLS with a token, then run SQL and bulk-load with the same surface as the in-process engine. Columnar results stay columnar on the wire.

How it fits together

These aren't eleven unrelated packages. Phasor is the vector-symbolic core — the holographic math. EvalApp is the runtime that schedules and self-tunes the heavy work. HoloDb, AlgFormer, Tracer, and HoloVoxel are what you get when you build a database, a transformer, a game-AI SDK, and a spatial engine on that same foundation — and the rest extend those four: HoloDb.Client/HoloDb.Protocol put HoloDb on the network, AlgFormer.Gpu puts AlgFormer's holographic core on a GPU, EvalApp.Neural swaps EvalApp's tuner for a learned one, and Prose uses HoloDb and AlgFormer together to grow a training corpus.
