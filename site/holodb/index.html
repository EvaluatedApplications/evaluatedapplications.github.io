What's inside

the engine

Real ACID

Transactions with a write-ahead log and crash recovery. Concurrent readers never block, and commits are durable — not an in-memory toy.

Constant-time aggregates

COUNT and SUM over integer columns are answered from maintained accumulators, independent of row count — the source of the 766× benchmark wins over per-scan engines.

Joins & similarity

Hash joins, a full boolean WHERE with compiled predicates, and holographic NEAREST similarity search over the same rows — SQL and vector retrieval in one engine.

Bigger than memory

An optional memory-mapped tier spills to disk when a table outgrows RAM, so the same API scales past what fits in memory.
