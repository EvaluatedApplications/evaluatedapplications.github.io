The software we've shipped.

Evaluated Applications builds high-performance .NET libraries. Most of them share one idea: computing with holographic vectors, over a runtime that tunes its own concurrency to your hardware. Everything below is on NuGet today. Add a package and go.

Foundation

the base everything shares

Phasor

v1.0.1
EvaluatedApplications.Phasor

Vector-symbolic computing for .NET. Bind, bundle, and unbind hyperdimensional / phasor (HRR) vectors with a SIMD codec — the holographic primitive the rest of these libraries are built on.

dotnet add package EvaluatedApplications.Phasor

EvalApp

v1.5.0
EvaluatedApplications.EvalApp

An async pipeline runtime: resource-gated concurrency with adaptive self-tuning, sagas with compensation, middleware, and a fluent builder. The shared execution engine underneath the other libraries.

Does the work of a MediatR + Polly + Dataflow stack — one dependency, ⅓ the allocation, zero dropped requests. See the benchmark →

Data

a holographic SQL database, embedded or networked

HoloDb

v1.3.0
EvaluatedApplications.HoloDb

An embeddable holographic SQL database. ACID with a write-ahead log, columnar storage with compiled predicates, constant-time integer aggregates, hash joins, similarity search, and an optional larger-than-memory tier. Concurrent reads.

Benchmarked vs DuckDB & SQLite to 10M rows — up to 766× faster on aggregates. See the numbers →

Also runs as a server — pull the image: docker pull ghcr.io/evaluatedapplications/holodb

dotnet add package EvaluatedApplications.HoloDb
Benchmarks →NuGet

HoloDb.Client

v1.0.0
EvaluatedApplications.HoloDb.Client

The .NET client for a remote HoloDb server. Connect over TLS with a token, then run SQL and bulk-load with the same surface as the in-process engine — swapping embedded for networked changes only how you get the handle. Columnar results stay columnar on the wire.

dotnet add package EvaluatedApplications.HoloDb.Client

How it fits together

These aren't nine unrelated packages. Phasor is the vector-symbolic core — the holographic math. EvalApp is the runtime that schedules and self-tunes the heavy work. HoloDb, AlgFormer, Tracer, and HoloVoxel are what you get when you build a database, a neural network, a game-AI SDK, and a spatial engine on top of that same foundation.
